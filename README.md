# TripKhojo – prototype

Clickable prototype of TripKhojo ("Travel More. Spend Smarter.") for internal testing.

- `index.html` – The Journey Engine: living globe, Budget Magic, Surprise Me
- `home.html` – Immersive homepage
- `tools.html` – Budget finder, AI planner demo, fare calendar
- `trip.html` – Sample trip page (Rishikesh)

All prices, fares and travel times are indicative sample estimates, not live prices.
Pages are marked `noindex` so search engines don't list the prototype.
